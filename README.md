# Wise Learner

Résumé IA, lecture audio et quiz à partir de PDF.

## Feuille de route
1. **Site web** (cette version) : page de présentation statique, `index.html`.
2. **Application** : React + TailwindCSS, API Django REST, PostgreSQL, OpenAI (voir cahier des charges).

## Lancer le site
Ouvrir `index.html` dans un navigateur, ou : `python -m http.server 8000`.
